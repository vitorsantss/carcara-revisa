# data-testid

Convenção: `tela-elemento[-detalhe]`. Ids com `<...>` recebem o id do registro.

Atributos auxiliares: `data-status`, `data-tipo`, `data-origem`, `data-conferida`, `data-state`, `data-etapa`, `data-visao`, `aria-pressed`.
